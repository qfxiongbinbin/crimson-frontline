# 《赤色前线：黎明协议》战场素材概念

本目录保存第一轮统一美术方向的素材概念板，暂未拆分为游戏内透明精灵图。

## 概念板

- `red-faction-buildings.png`：兵工厂、兵营、资源精炼厂、发电站
- `red-faction-units.png`：步兵、火箭兵、轻型坦克、重型坦克、采矿车、基地工程车
- `battlefield-props.png`：地表、岩石、金晶矿、沙袋、拒马、弹坑、残骸、补给箱、防御墙、警示灯

## 统一美术规范

- 镜头：高位正俯视、正交投影，避免明显透视变形
- 阵营：红色装甲板 + 炭黑钢结构 + 暖琥珀识别灯
- 战场：低饱和橄榄褐地表、深灰岩石、琥珀色矿物
- 质感：轻度战损和磨损，但保持轮廓完整、缩小后仍可识别
- 光照：克制的顶部光，避免大范围投影和环境反光
- 图形：不使用文字、商标、旗帜和复杂徽记

## 建议落地规格

- 地图格：继续使用 `32×32 px`
- 步兵：画布建议 `32×32 px`，主体约 `20–24 px`
- 车辆：轻坦 `48×48 px`，重坦/采矿车/工程车 `56×56 px`
- 建筑：按照现有占地输出为 `64×64`、`96×64` 或 `96×96 px`
- 正式精灵需逐个重绘或拆分为透明 PNG，并额外制作选中、受击、施工和阵亡状态
